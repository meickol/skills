# meickol/skills

A collection of Claude Code skills installable via the [skills CLI](https://github.com/vercel-labs/skills).

## Install

```bash
npx skills@latest add meickol/skills
```

The CLI will ask which skills to install and which agents to install them to.

## Skills

### teach-me

Pedagogical teacher mode. Explains concepts with strong didactic structure (Feynman, scaffolding, dual coding, active recall) and builds a per-topic visual HTML reference book saved to `~/.claude/teaching/`.

Use it: `/teach-me <concept>`

### html

Generates self-contained, interactive HTML files instead of markdown for any output with structure, comparison, hierarchy, or interactivity potential.

Use it: `/html` or ask to "document", "explain", "compare", "summarize", "make a report".
